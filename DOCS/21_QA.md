# 🧪 21. QUALITY ASSURANCE, DETEKT COMPLIANCE & STATIC ANALYSIS
**Project**: UniCalculator (Bharat Pro Financial & GST Neumorphic Calculator)

---

## 1. Zero-Shortcut Quality Rules (AGENTS.md Strict Mandate)

1. **NO `@Suppress` Annotations**:
   - Using `@Suppress` annotations to bypass Detekt, Spotless, or Android Lint is strictly forbidden.
   - Any static analysis warnings must be fixed structurally (Parameter Objects, splitting helper classes, formatting multi-line annotations).
2. **Deterministic Code Formatting**:
   - Every build must pass `./gradlew spotlessCheck detekt` with **0 errors and 0 warnings**.
3. **Paparazzi Screenshot Regression Tests**:
   - Snapshot testing for all Neumorphic button states (Extruded, Inset, Glowing) across multiple screen densities (hdpi, xhdpi, xxhdpi, xxxhdpi) and theme modes (Light Vintage, Dark Obsidian).

---

## 2. Performance Profiling Gates (Perfetto Benchmarks)
- **Frame Render Time**: 99th percentile frame render time < 8.33ms (120 FPS target).
- **Keypad Input Latency**: Input dispatch to recomposition < 3.2ms.
- **Cold App Start**: < 70ms cold launch with Macrobenchmark Baseline Profiles.
- **Memory Footprint**: < 14MB RAM utilization during continuous calculation sessions.
