## 3. Key Component Anatomy & Measurements

### 3.1 Neumorphic Tactile Key (`NeumorphicButton`)
- **Dimensions**:
  - Compact: `72dp × 64dp` (Dynamic flex width in 4-column grid).
  - Corner Radius: `20dp` (Continuous squircle).
- **Resting State (Convex)**:
  - Surface Color: Same as background (`#E8E5DF` / `#1E2228`).
  - Top-Left Light Glow: Blur `10dp`, Offset `(-5dp, -5dp)`.
  - Bottom-Right Dark Shadow: Blur `10dp`, Offset `(5dp, 5dp)`.
- **Pressed State (Concave)**:
  - Inner Top-Left Dark Inset: Blur `6dp`, Offset `(3dp, 3dp)`.
  - Scale factor: Smoothly scales to `0.97f` with spring damping `0.75f`.
- **Text & Glyph Styling**:
  - Numbers: `JetBrains Mono` / `Inter` Bold, Size `24sp`, Color `#212121` (Light theme) / `#F5F5F5` (Dark theme).
  - Operators (`+`, `-`, `×`, `÷`, `=`): Emerald Green / Saffron Orange accent tint.

### 3.2 Recessed Neumorphic LCD Well (`NeumorphicLCDWell`)
- **Dimensions**:
  - Height: `180dp` (Phones) / `240dp` (Tablets).
  - Corner Radius: `24dp`.
  - Shape: **CONCAVE (Inner Inset Well)**.
- **Visual Stacking**:
  - Line 1: `History / Expression Line` (Size `16sp`, Monospace, Alpha `60%`, Right Aligned).
  - Line 2: `Primary Result Line` (Dynamic Font Auto-Scaler: `44sp` down to `20sp`, Bold Monospace).
  - Line 3: `Indian Words Translation Badge` (Size `13sp`, Italic, Alpha `75%`, e.g., *"Twenty Thousand Rupees Only"*).

### 3.3 Neumorphic GST Slab Bar (`GSTSlabRow`)
- **Layout**: Horizontal row of 4 or 5 extruded capsule pill buttons.
- **Slabs**: `+5%`, `+12%`, `+18%`, `+28%` (and toggle for `-5%`, `-12%`, `-18%`, `-28%`).
- **Active Selection**: Glowing amber/emerald accent ring with inset inner glow.
